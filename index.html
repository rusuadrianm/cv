Proposed first 90 days as Service Management Coordinator

How the same habits would carry into GBS governance

Days 1–30

Learn the system

  • Map the GBS service catalogue, service lines, SLAs and KPI definitions.
  • Sit in on each governance routine once: service reviews, control check-ins, incident reviews.
  • Meet the control owners in France and Belgium and agree how and when we report.
Days 31–60

Make performance visible

  • Baseline KPI and SLA trends and build one Power BI service pack shared by all service lines.
  • Automate the data refresh and remove manual steps from the monthly pack.
  • Set up a single tracker for remediation actions, with owners and due dates.
Days 61–90

Run the rhythm, then improve it

  • Run the service review cycle from the new pack and escalate risks with data behind them.
  • Start post-incident reviews on a standard template, with trend analysis across incidents.
  • Propose the first automation and standardization backlog, with the effort each item saves.
